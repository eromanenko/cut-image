# Детальна інструкція: Навчання YOLOv8-OBB у Google Colab

Ця інструкція допоможе вам безкоштовно натренувати власну модель для розпізнавання карток (з використанням OBB - повернутих прямокутників) на потужних серверах Google. 

Ми розберемо два сценарії:
1. **Ваш власний датасет** (зібраний через телеметрію застосунку `cut-image`).
2. **Датасет MIDV-500** (публічний датасет із Hugging Face).

---

## Етап 1: Підготовка середовища

### 1.1. Створення Notebook'а
1. Відкрийте [Google Colab](https://colab.research.google.com/).
2. Увійдіть у свій Google-акаунт (той самий, де ваш Google Диск).
3. Натисніть **"New notebook"** (Новий блокнот).

### 1.2. Увімкнення відеокарти (GPU)
Це критично важливий крок, щоб навчання тривало хвилини, а не дні.
1. У верхньому меню Colab натисніть `Runtime` (Середовище виконання) -> `Change runtime type` (Змінити тип середовища).
2. У випадаючому списку "Hardware accelerator" (Апаратний прискорювач) виберіть **T4 GPU**.
3. Натисніть **Save** (Зберегти).

### 1.3. Підключення Google Диска
Щоб Colab міг брати ваші картинки і зберігати туди готову модель (щоб вона не зникла, коли ви закриєте вкладку), треба підключити Диск.
Вставте цей код у першу клітинку Colab і натисніть кнопку **Play** (▶️) ліворуч від неї:

```python
from google.colab import drive
drive.mount('/content/drive')
```
*Вас попросять дати дозвіл на доступ до вашого Google Диска — погодьтесь.*

### 1.4. Встановлення YOLO
У новій клітинці вставте та запустіть наступний код (знак оклику `!` означає, що це команда терміналу, а не Python-код):

```bash
!pip install ultralytics
```

## Етап 2: Навчання (Оберіть один із варіантів)

> [!TIP]
> У Colab ви можете створювати нові клітинки для коду, натискаючи кнопку **"+ Code"** під існуючими клітинками.

### Варіант А: Навчання на Вашому власному датасеті

Перед тим, як почати в Colab, ви маєте підготувати дані на своєму комп'ютері:
1. Виконайте команду з вашого `ML_INSTRUCTION.md`, щоб скачати телеметрію: `python scripts/download_dataset.py`.
2. У вас з'явиться папка `dataset`. Заархівуйте її у файл `dataset.zip`.
3. Завантажте `dataset.zip` у корінь вашого Google Диска.

Тепер повертаємось у Colab. Створіть клітинку і розпакуйте датасет:

```bash
# Розпаковуємо ваш архів з Диска в локальну пам'ять Colab
!unzip /content/drive/MyDrive/dataset.zip -d /content/
```

Коли датасет розпаковано, запускаємо тренування:

```bash
# Запускаємо навчання (epochs=50 - кількість проходів, imgsz=1024 - розмір картинки)
!yolo task=obb mode=train data=/content/dataset.yaml model=yolov8n-obb.pt epochs=50 imgsz=1024
```

### Варіант Б: Навчання на датасеті MIDV-500 (з Hugging Face)

Якщо ви хочете потренуватись на готових даних, вам навіть не треба використовувати Google Диск для завантаження фотографій — Colab скачає їх напряму з інтернету!

Створіть клітинку та встановіть бібліотеку `datasets`:
```bash
!pip install datasets huggingface_hub
```

Напишіть Python-скрипт (в наступній клітинці), який завантажить MIDV-500 та конвертує його в зрозумілий для YOLO-OBB формат:
*(Цей крок може бути дещо складнішим, оскільки оригінальний MIDV-500 повертає координати у форматі JSON полігонів. На практиці вам знадобиться невеликий Python-скрипт конвертації, який створює папки `images/` та `labels/` і файл `dataset.yaml`, аналогічний тому, що робить ваш локальний скрипт телеметрії).*

Для простоти, припустимо, що у нас є готовий конвертований датасет MIDV у форматі YOLO-OBB (або ми використовуємо ваш скрипт). Формат запуску навчання буде ідентичним:

```bash
!yolo task=obb mode=train data=шлях_до_midv_dataset.yaml model=yolov8n-obb.pt epochs=50 imgsz=1024
```

## Етап 3: Експорт та Збереження результату

> [!IMPORTANT]
> Після завершення тренування (коли всі "епохи" пройдуть), ваша найкраща модель буде збережена локально в Colab у папці `runs/obb/train/weights/best.pt`. **Якщо ви зараз закриєте вкладку, вона назавжди зникне!**

Щоб зберегти результати і конвертувати їх для вашого сайту:

1. Спочатку експортуємо навчену модель у формат ONNX (для браузера):
```bash
!yolo export model=/content/runs/obb/train/weights/best.pt format=onnx imgsz=1024
```

2. Тепер копіюємо експортований `.onnx` файл на ваш надійний Google Диск:
```bash
!cp /content/runs/obb/train/weights/best.onnx /content/drive/MyDrive/my_custom_card_model.onnx
```

### Фінал! 🎉
Тепер ви можете зайти на свій Google Диск з комп'ютера, скачати файл `my_custom_card_model.onnx`, перейменувати його на `best.onnx` і покласти у папку `models/` вашого проєкту `cut-image`.

Вітаю, ви успішно використали хмарні обчислення!
